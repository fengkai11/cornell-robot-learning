# Clip 04：强化学习、奖励诊断与 Residual RL

## 1. 本阶段目标

本阶段不把强化学习当作“比 BC 更高级的替代品”，而是研究它在接触不确定性、局部修正和失败恢复中的作用。

主线是：

> 传统控制或 BC 提供可工作的基础行为，Residual RL 只学习难以建模的局部修正。

RL from scratch 作为对照，用于观察探索空间、奖励设计和样本效率问题。

## 2. 任务边界

第一版 RL 只覆盖接触阶段，不负责：

- 语言理解；
- 全局对象选择；
- 大范围自由空间规划；
- 抓取前的复杂视觉感知。

建议状态：

```text
object_to_target_pose
insertion_depth
contact_or_force_proxy
qpos/qvel subset
previous_action
progress_window
phase_id
```

建议残差动作：

```text
[dx_residual, dy_residual, dz_residual,
 droll_residual, dpitch_residual, dyaw_residual]
```

优先从平移残差开始，再决定是否开放旋转残差。

## 3. Residual RL 形式

基础动作来自传统控制器或 BC：

$$
a_t=a_t^{base}+\alpha a_t^{res}.
$$

其中：

- `base` 负责正常轨迹和基本安全性；
- `residual` 负责局部纠偏；
- `alpha` 限制残差控制权；
- 最外层 safety filter 对最终动作再次限幅。

必须记录：

- 基础动作；
- 原始残差；
- 缩放后残差；
- 安全过滤后的最终动作。

## 4. 奖励设计

从可解释的小奖励开始：

$$
r_t=w_p\Delta d_t-w_{xy}\|e_t^{xy}\|-w_R\|e_t^R\|-w_f c_t^{unsafe}+r_{success}-r_{failure}.
$$

其中：

- `Δd`：插入进展；
- `e_xy`：横向误差；
- `e_R`：姿态误差；
- `c_unsafe`：危险接触或越界；
- 终止奖励只在可信 success 条件满足时给出。

每个奖励项都必须回答：

1. 真实部署时是否可计算；
2. 是否使用仿真真值；
3. 是否会诱导危险捷径；
4. 权重变化会如何改变行为；
5. 它是训练辅助还是实际任务目标。

## 5. Codex 实现任务

### Task 04A：RL 环境封装

- 将任务裁剪到接触阶段；
- 支持从专家或 BC 到达的初始状态；
- 实现 observation/reward/action wrapper；
- 分离环境 success 和训练 reward。

### Task 04B：RL from scratch 基线

- 选择一个成熟 PPO 或 SAC 实现；
- 配置化并行环境、网络和随机种子；
- 保存训练曲线和评测 checkpoint；
- 禁止为了“跑起来”静默改变任务定义。

### Task 04C：Residual RL

- 加载基础控制器或 BC；
- 实现残差叠加和 safety filter；
- 支持仅在接触或卡滞 phase 开启残差；
- 比较不同 `alpha`。

### Task 04D：奖励与行为诊断

- 输出每个奖励分量；
- 自动检查无进展、震荡、大力挤压和越界；
- 保存高回报但失败的 episode；
- 生成奖励与真实任务指标的相关性报告。

## 6. 必做对照

| 方法 | 目的 |
|---|---|
| RL from scratch | 观察探索与样本效率 |
| 传统控制 / BC | 基础能力 |
| Residual RL | 验证局部修正 |
| BC + DAgger | 与数据纠正路线比较 |
| 随机残差 | 排除简单噪声带来的偶然收益 |

所有方法使用相同测试分布和安全约束。

## 7. 必做实验

### 实验 A：残差控制范围

比较：

- 仅平移；
- 平移加旋转；
- 仅在卡滞时启用；
- 全阶段启用。

### 实验 B：残差幅度

比较至少三个 `alpha`，观察成功率、最大接触力、震荡和恢复率。

### 实验 C：奖励消融

逐项删除一个奖励分量，分析行为变化，而不是只看总回报。

### 实验 D：动力学随机化

改变摩擦、质量、间隙和控制延迟，观察 Residual RL 是否真的提高鲁棒性。

## 8. 奖励投机检查

重点寻找：

- 倾斜挤压获得插入深度；
- 高频震荡累积进展奖励；
- 施加大力快速完成；
- 在 success 边界附近反复触发；
- 延长 episode 获取存活奖励；
- 利用仿真碰撞或接触模型漏洞。

发现高回报失败轨迹时，应优先修正任务判定和奖励，而不是增加训练步数。

## 9. 主动修改任务

至少完成：

- 改变残差幅度；
- 将 RL 从全流程缩小到接触阶段；
- 删除一个 reward 项；
- 修改无进展窗口；
- 将仿真真值奖励替换为可测量代理；
- 加入动作平滑或变化率限制。

## 10. 故障注入

主动制造：

- 奖励符号写反；
- `terminated` 和 `truncated` 混淆；
- 基础动作和残差动作量纲不同；
- 训练时基础策略处于随机或 dropout 模式；
- safety filter 只用于评测、不用于训练；
- 多环境 reset 状态互相污染；
- 总回报提高但成功率下降。

## 11. 应用映射

真实系统中必须考虑：

- 接触力来自传感器还是电流估计；
- RL 探索是否会损坏工件；
- 是否先在仿真训练再在真实环境小幅适配；
- residual 是否受工作空间和力限制；
- 基础策略失效时 residual 是否仍安全；
- 如何检测无进展并切换到恢复策略。

## 12. 阶段产物

- RL 接触阶段环境；
- RL from scratch 基线；
- Residual RL 实现；
- 奖励分量和行为诊断；
- 残差幅度、控制范围和奖励消融；
- 仿真随机化鲁棒性测试；
- 高回报失败案例库。

## 13. 通过门槛

- 能解释为什么 RL from scratch 样本效率低或失败；
- Residual RL 的收益来自可重复实验而非个别轨迹；
- 最大接触力和安全事件没有因成功率提升而恶化；
- 至少识别一种奖励投机；
- 能说明 DAgger 与 Residual RL 分别适合什么失败；
- 能提出真实机器人上安全适配的最小方案。
