# Clip 06：混合系统集成、传感器接口与 Sim2Real 准备

## 1. 本阶段目标

将前面的控制器、BC、DAgger、Residual RL 和语言条件策略组合成可诊断的机器人系统，并逐步删除仿真特权信息。

本阶段的关键问题是：

> 当目标位姿不再是准确真值、接触信息存在延迟、模型输出可能异常时，整个系统如何继续安全工作？

## 2. 推荐分层架构

```text
Task Manager
├── 指令解析与目标选择
├── Phase State Machine
│   ├── APPROACH
│   ├── ALIGN
│   ├── CONTACT
│   ├── INSERT
│   ├── VERIFY
│   └── RECOVER
├── Skill Policies
│   ├── 传统规划 / 视觉伺服
│   ├── BC / ACT / VLA
│   └── Residual RL
├── Safety Supervisor
└── Logger and Failure Monitor
```

策略之间不直接互相调用，由任务管理器和状态机调度。

## 3. 模块契约

每个模块必须定义：

- 输入字段；
- 输出字段；
- 坐标系；
- 单位；
- 更新频率；
- 时间戳；
- 置信度；
- 超时行为；
- 错误码；
- 回退策略。

建议统一策略接口：

```text
PolicyInput
- timestamp
- observations
- task_condition
- phase
- previous_action

PolicyOutput
- raw_action
- confidence
- valid_until
- diagnostics
- requested_transition
```

## 4. 坐标系与标定

至少画出：

```text
base
├── end_effector / tcp
├── camera
├── object
└── target
```

真实系统常用变换：

$$
{}^{base}T_{object}={} ^{base}T_{camera}{}^{camera}T_{object}.
$$

必须明确：

- `base_T_camera` 来自手眼标定还是固定外参；
- `camera_T_object` 来自什么视觉算法；
- TCP 标定怎样获得；
- 标定误差如何传递到插入误差；
- 外参多久检查一次；
- 时间不同步会产生什么等效位姿误差。

## 5. 逐步删除仿真特权信息

按照以下顺序推进，不要一次从真值跳到纯图像：

```text
真值目标位姿
→ 加高斯与偏置噪声
→ 加时间延迟和丢帧
→ 使用独立状态估计器输出
→ 使用 RGB-D 或 RGB 估计
→ 加相机外参误差
→ 加遮挡与光照变化
```

每一步都记录：

- 成功率下降；
- 主要失败类型；
- 哪个模块最先失效；
- 是否能通过反馈或恢复补偿；
- 是否值得更换传感器或改善治具。

## 6. 传感器与实际观测映射

| 所需量 | 仿真来源 | 真实候选来源 | 主要问题 |
|---|---|---|---|
| 机械臂状态 | 仿真 articulation | 编码器/控制器 | 时间戳与滤波 |
| TCP 位姿 | 真值 FK | 标定模型 + FK | TCP 偏差 |
| 对象位姿 | actor pose | RGB-D/标记/位姿估计 | 遮挡与对称性 |
| 目标位姿 | actor pose | 工装标定/视觉估计 | 外参漂移 |
| 接触力 | 仿真接触 | 六维力传感器/电流 | 偏置、带宽 |
| 插入进展 | 几何真值 | FK + 目标轴估计 | 误差累积 |
| 卡滞状态 | 规则真值 | 力、位移和无进展窗口 | 阈值泛化 |

## 7. Safety Supervisor

学习策略输出必须经过：

- 工作空间检查；
- 速度和单步位移限制；
- 关节限位；
- 接触力或代理信号限制；
- 动作变化率限制；
- 置信度和数据新鲜度检查；
- 超时与心跳检查；
- 连续失败次数限制。

推荐回退：

```text
观测过期 → hold / stop
置信度低 → 使用传统基线或请求人工
无进展 → retract and retry
接触异常 → immediate retract
多次失败 → safe pose + manual intervention
```

## 8. Codex 实现任务

### Task 06A：统一接口

- 创建 observation、action、diagnostic 数据类；
- 加单位和坐标系元数据；
- 编写模块契约测试；
- 禁止模块间使用未声明字段。

### Task 06B：状态机和策略路由

- 独立实现 phase transitions；
- 策略只提供动作或转换建议；
- 任务管理器决定最终切换；
- 保存每次切换原因。

### Task 06C：Safety Supervisor

- 在所有策略外层执行；
- 支持动作裁剪、拒绝和紧急回退；
- 编写越界、过期观测和异常力测试；
- 日志区分策略动作与安全后动作。

### Task 06D：传感器退化包装器

- 位姿噪声、固定偏置、延迟、丢帧；
- 接触信号噪声和饱和；
- 相机遮挡与光照变化；
- 配置化组合并保存随机种子。

### Task 06E：系统回放

- 支持从 episode 日志重放状态机决策；
- 生成故障时间线；
- 输出首个异常点，而不只输出最终失败。

## 9. 必做实验

### 实验 A：策略组合

比较：

- 单一端到端策略；
- 传统抵近 + BC 插入；
- 传统抵近 + BC + Residual RL；
- VLA 高层选择 + 传统/学习技能；
- 加入与不加入安全监督器。

### 实验 B：观测退化阶梯

按特权信息删除顺序逐级测试，形成性能阶梯图。

### 实验 C：延迟和频率

改变：

- 感知频率；
- 策略推理频率；
- 底层控制频率；
- 固定和随机延迟。

记录稳定性、周期时间和失败模式。

### 实验 D：恢复策略

为位置误差、卡滞、观测过期和策略异常分别验证回退。

## 10. 主动修改任务

至少完成：

- 将一种仿真真值替换为带噪估计；
- 增加固定外参偏置；
- 将策略更新频率降低一半；
- 调整安全动作上限；
- 将一种策略从全程启用改为 phase 条件启用；
- 添加一个新故障码和恢复路径。

## 11. 故障注入

主动制造：

- 相机外参方向写反；
- 时间戳使用不同时间基准；
- 旧观测被重复使用；
- phase 切换后策略内部状态未清空；
- safety filter 与环境动作单位不一致；
- VLA 推理超时但系统继续执行旧动作；
- 恢复动作再次进入原卡滞状态；
- 日志只保存过滤后动作，无法定位策略异常。

## 12. 最小真实验证建议

在具备桌面机械臂后，先做低风险版本：

- 大间隙插销；
- 3D 打印或简单治具；
- 单相机或标记辅助；
- 低速度；
- 软质或易更换工件；
- 人工复位；
- 传统控制基线优先；
- 学习策略只在有限工作空间内生效。

真实实验的首要目标不是成功率，而是经历：

- 驱动和控制接口；
- TCP 与相机标定；
- 时间同步；
- 观测噪声；
- 动作延迟；
- 安全停止；
- 日志与复现。
