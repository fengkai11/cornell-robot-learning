# Clip 00：应用定义、验收指标与失败分类

## 1. 本阶段目标

本阶段禁止先讨论 BC、PPO、VLA 或网络结构。目标是把一个模糊的“机器人装配任务”转化为可以实施和验收的应用问题。

完成后应能够不依赖算法名称回答：

- 机器人要完成什么；
- 初始条件允许怎样变化；
- 成功、失败和危险分别是什么；
- 客户或使用者如何判断系统合格；
- 哪些失败允许自动重试，哪些必须停止；
- 为什么值得引入学习算法。

## 2. 默认应用场景

在桌面工作站中，机械臂将插销或齿轮安装到指定孔位或轴上。场景包含：

- 至少两种可操作对象；
- 至少两个目标位置；
- 自由空间抵近和接触插入两个明显阶段；
- 位置、姿态、摩擦、间隙和观测噪声变化；
- 侧碰、卡滞、无进展和抓取不稳等失败状态；
- 正常执行、后退、抬起重试和人工接管等恢复动作。

第一版只做单对象、单目标、状态观测。多对象、语言条件和视觉输入在后续 clip 加入。

## 3. 任务边界

### 3.1 输入

- 任务配置或语言指令；
- 机械臂本体状态；
- 对象与目标的状态估计；
- 可选 RGB、深度和接触信息；
- 当前任务阶段和历史动作。

### 3.2 输出

- 目标或技能选择；
- 末端增量动作或关节动作；
- 成功、失败、重试、停止等系统状态；
- 完整日志和失败类型。

### 3.3 不在第一版范围内

- 高速工业节拍；
- 无人值守连续运行数百小时；
- 高危险力矩或尖锐工件；
- 大型 VLA 全参数训练；
- 一开始就完成真实机器人精密小间隙插装。

## 4. 初始验收指标

以下指标是课程设计的起始值，不是假定的工业标准。Clip 01 完成基线后，应根据任务难度重新校准。

| 维度 | 初始指标 |
|---|---|
| 正常分布成功率 | ≥ 90% |
| 轻度位置扰动成功率 | ≥ 75% |
| 卡滞检测召回率 | ≥ 80% |
| 卡滞后恢复成功率 | ≥ 60% |
| 危险力或越界事件 | 0 |
| 平均重试次数 | ≤ 1.5 |
| 结果可复现性 | 至少 3 个随机种子 |
| 失败可诊断性 | 所有失败有明确类型和日志 |

每个指标必须说明：

- 测量方法；
- 采样数量；
- 是否依赖仿真真值；
- 置信区间或不同随机种子方差；
- 适用的扰动范围。

## 5. 失败分类

第一版至少包含以下失败码：

```text
PERCEPTION_TARGET_MISSING
PERCEPTION_POSE_ERROR
PLANNING_UNREACHABLE
APPROACH_COLLISION
ALIGNMENT_OUT_OF_TOLERANCE
CONTACT_FORCE_EXCEEDED
INSERTION_NO_PROGRESS
INSERTION_JAMMED
OBJECT_DROPPED
POLICY_OSCILLATION
TIMEOUT
RECOVERY_FAILED
SAFETY_WORKSPACE_VIOLATION
```

失败不能只记录为 `success=False`。每个失败码至少保存：

- episode id；
- 随机种子；
- 环境参数；
- 最近若干步观测与动作；
- 末端轨迹；
- 接触力或替代信号；
- 失败时截图或视频索引。

## 6. 系统拆解练习

先画出下面的系统链条，并为每个环节填写首选方法和备选方法：

```text
任务输入
→ 对象与目标确定
→ 位姿获取
→ 自由空间抵近
→ 精细对准
→ 接触检测
→ 插入控制
→ 成功判断
→ 异常恢复
```

每个环节回答：

1. 传统方法能否完成；
2. 使用学习的必要性是什么；
3. 所需观测如何在真实系统中获得；
4. 失败时如何回退；
5. 是否需要高频闭环。

## 7. Codex 实现任务

让 Codex 只生成以下文档和数据结构，不让它替你决定需求：

- `TaskSpecification` 配置 schema；
- `AcceptanceCriteria` 配置 schema；
- `FailureCode` 枚举；
- episode 日志字段定义；
- 配置文件校验测试；
- 一个用于汇总成功率和失败分布的空评测脚本。

推荐 Codex 任务：

```text
请在 06-capstone-project/implementation 中创建纯数据结构和配置校验代码，
不要实现机器人环境和学习算法。要求定义任务规格、验收指标、失败码和
episode 日志 schema，并为必填字段、非法阈值和未知失败码编写单元测试。
```

## 8. 你必须完成的接管任务

### 8.1 解释

不看代码，说明：

- 成功条件与奖励函数的区别；
- 失败检测与策略训练的区别；
- 为什么周期时间和安全事件也是算法评价的一部分；
- 为什么“仿真成功率 95%”不能直接代表可交付。

### 8.2 主动修改

至少修改一项：

- 扰动范围；
- 成功位置阈值；
- 最大允许接触力；
- 重试次数；
- 超时条件。

并说明该修改会怎样改变任务难度和系统风险。

### 8.3 故障注入

主动制造：

- 缺失必填指标；
- 成功阈值为负数；
- 未注册失败码；
- 日志中缺少随机种子。

确认测试能够阻止错误配置进入后续实验。

## 10. 通过门槛

只有满足以下条件才进入 Clip 01：

- 能用 3 分钟讲清任务，而不先提算法；
- 每个验收指标都有测量定义；
- 至少列出 10 类可区分失败；
- 明确哪些输入是仿真特权信息；
- 能说明学习算法相对传统方案可能带来的具体价值。
