# 课程设计：应用驱动的机器人学习装配系统

本目录用于承接 Cornell CS 4756/5756 Robot Learning 的课程知识，将控制、模仿学习、强化学习、视觉策略和 VLA 汇合到一个可逐步实现、可诊断、可迁移到真实机器人的课程设计中。

## 1. 项目定位

课程设计不以“运行了多少算法”为目标，而以能否完成以下闭环为标准：

> 真实需求定义 → 系统拆解 → 非学习基线 → 数据与学习策略 → 失败诊断 → 系统集成 → 真实部署准备

建议题目：

> **面向精密装配的传统控制、模仿学习、残差强化学习与语言条件策略混合系统**

默认任务是在 ManiSkill 中完成带位置、姿态、摩擦和观测扰动的 Peg/Gear Insertion：

> 目标选择 → 抵近 → 精细对准 → 接触插入 → 成功判断 → 卡滞恢复

项目最终必须回答：

1. 哪些环节适合传统控制或规划；
2. 哪些环节适合模仿学习；
3. 哪些长尾状态值得使用 DAgger 或强化学习；
4. VLA 是否真正利用语言和视觉，而不是记忆固定任务；
5. 仿真结果距离真实部署还缺少哪些传感器、标定、安全和系统能力。

## 2. 学习模式：AI 生成，人类接管

Codex 可以生成代码、测试、配置和实验脚本，但“代码生成完成”不等于“学习完成”。每个 clip 固定执行：

```text
先预测 → Codex 实现 → 阅读接口与张量 → 运行验证
→ 主动修改 → 故障注入 → 复现实验 → 独立解释
```

每个 clip 通过以下四项才算完成：

- **能画出来**：画出数据流、控制流和关键状态转换；
- **能解释**：不看代码说明输入、输出、目标函数和失败模式；
- **能修改**：主动改变一个关键设计，并保持系统可运行；
- **能诊断**：面对失败提出原因排序和验证实验。

Codex 的角色是高效率实现工程师；用户是任务定义者、代码审查者和实验负责人。

## 3. 系统架构

```text
语言指令 / 任务配置
          ↓
目标与技能选择（后期加入语言条件策略或 VLA）
          ↓
传统规划与控制：自由空间抵近
          ↓
BC / ACT：精细对准与正常插入
          ↓
Residual RL：接触修正与卡滞恢复
          ↓
状态机：成功、重试、后退、停止、人工接管
```

端到端策略可以作为对照，但不默认它优于分层混合系统。

## 4. Clip 路线

| Clip | 主题 | 核心产物 | 进入下一阶段的门槛 |
|---|---|---|---|
| 00 | 应用定义与验收 | 任务规格、指标、失败分类 | 不依赖算法名称也能说明问题 |
| 01 | 环境与传统基线 | ManiSkill 环境、状态机、专家 | 环境可测试，成功条件可信 |
| 02 | 专家数据与 BC | 数据集、BC、闭环评测 | 能解释训练损失与闭环差距 |
| 03 | DAgger 与分布偏移 | 纠正数据闭环、对照实验 | 证明数据分布比单纯数量重要 |
| 04 | RL 与 Residual RL | RL 基线、残差策略、安全约束 | 能诊断奖励投机和接触失败 |
| 05 | 语言条件策略与 VLA | Language-ACT、SmolVLA 适配 | 证明语言真正改变目标或技能 |
| 06 | 系统集成与 Sim2Real | 混合系统、部署差距清单 | 去除关键仿真特权信息后仍可运行 |
| 07 | 最终评测与答辩 | 对照实验、报告、视频、答辩 | 结论有证据且明确适用边界 |

对应文档见 [`clips/`](clips/)。

## 5. 4060 笔记本约束

项目默认按 RTX 4060 Laptop GPU 的显存、散热和持续功耗约束设计：

- 数据采集、模型训练和视频评测分开运行；
- 优先状态策略、单相机和低分辨率图像；
- 先完成 BC/ACT，再接入 VLA；
- SmolVLA 优先冻结骨干、训练动作头或使用 PEFT/LoRA；
- 不把大型 VLA 全参数训练作为结业门槛；
- RL 优先使用低维状态和小型残差网络；
- 所有实验记录显存峰值、推理延迟和控制频率。

## 6. 应用导向硬约束

每个算法模块都必须回答：

1. 它对应真实系统的哪个环节；
2. 不使用学习算法时如何解决；
3. 所需观测在真实环境中如何获得；
4. 数据从哪里来、代价多大；
5. 失败后如何检测、回退和记录；
6. 性能提升是否值得增加系统复杂度；
7. 工业价值是什么；
8. 向家庭机器人迁移时可复用什么。

仿真观测必须标记为：

- 可直接测量；
- 需要估计；
- 仅仿真可得的特权信息；
- 真实系统暂时不可获得。

## 7. 最终对照组

最低对照矩阵：

| 编号 | 方法 | 目的 |
|---|---|---|
| B0 | 传统控制 / Scripted Expert | 建立系统基线和数据来源 |
| B1 | Behavior Cloning | 验证监督模仿和闭环误差 |
| B2 | BC + DAgger | 验证策略访问分布修正 |
| B3 | RL from scratch | 观察探索、奖励和样本效率 |
| B4 | BC/控制器 + Residual RL | 验证混合路线 |
| B5 | Language-conditioned ACT | 验证多任务语言条件 |
| B6 | SmolVLA 参数高效适配 | 验证预训练和组合泛化 |

并非所有高级模型都必须成功；失败但有严格诊断和对照，同样属于有效课程成果。
