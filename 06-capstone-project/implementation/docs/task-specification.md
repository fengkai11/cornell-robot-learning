# Clip 00 任务规格与应用边界

## 1. 一句话任务定义

机械臂在桌面工作站中，将已抓持的单个齿轮移动到固定轴上方，完成抵近、对准、接触和插入，并在异常时记录可区分的失败原因。

第一版只使用单对象、单目标和状态观测。它不是完整工业交付系统，而是后续控制、BC、DAgger、Residual RL 和 VLA 的统一应用合同。

## 2. 系统流程

```text
任务配置
→ 确认齿轮与目标轴
→ 获取机械臂、齿轮和轴位姿
→ 自由空间抵近
→ 精细位置与姿态对准
→ 接触检测
→ 插入控制
→ 成功判断
→ 重试、停止或人工接管
```

## 3. 成功、失败与危险

### 成功

- 齿轮达到规定插入深度；
- 横向位置误差不超过配置阈值；
- 姿态误差不超过配置阈值；
- 未发生危险接触力或工作空间越界；
- 在最大时间和重试次数内完成。

成功判定是评测合同，不等同于奖励函数。后续算法可以使用不同训练信号，但都必须接受同一成功条件评测。

### 失败

失败必须使用 `FailureCode` 分类，并保存随机种子、环境参数、最近观测与动作、TCP 轨迹、接触力和视频索引。`success=false` 但没有失败码属于非法日志。

### 危险

`CONTACT_FORCE_EXCEEDED` 与 `SAFETY_WORKSPACE_VIOLATION` 默认要求立即停止，不能自动重试。

## 4. 传统方案与学习方案

| 环节 | 第一选择 | 学习方法可能带来的价值 | 第一版回退 |
|---|---|---|---|
| 目标确认 | 配置或仿真真值 | 后续用 VLA 处理多对象和语言指令 | 目标不明确则停止 |
| 位姿获取 | 仿真真值或几何估计 | 学习感知可处理复杂外观，但需置信度 | 重新观测或人工处理 |
| 自由空间抵近 | 运动规划与位置控制 | 通常没有必要端到端学习 | 规划失败则停止 |
| 精细对准 | 视觉伺服或闭环控制 | BC 可吸收难以显式建模的误差 | 后退并重新对准 |
| 接触插入 | 顺应控制、力控 | Residual RL 可学习摩擦与间隙修正 | 接触异常则后退 |
| 异常恢复 | 规则状态机 | DAgger/RL 可处理长尾卡滞状态 | 重试次数耗尽后人工接管 |

## 5. 仿真观测与真实来源

| 观测 | Clip 01 来源 | 真实系统可能来源 | 风险 |
|---|---|---|---|
| `robot_qpos`、`robot_qvel` | 编码器状态 | 机械臂控制器 | 时间戳和单位不一致 |
| `tcp_pose` | 正运动学 | 机械臂控制器 | TCP 标定误差 |
| `gear_pose` | 仿真真值 | RGB-D/双目/位姿估计 | 遮挡、标定和延迟 |
| `shaft_pose` | 仿真真值 | 视觉定位或固定治具标定 | 坐标系漂移 |
| `contact_force` | 仿真接触力 | 六维力传感器、关节力矩或电流估计 | 采样频率、噪声和偏置 |

## 6. 第一版真实部署差距

1. 尚未建立相机到机械臂基座的外参标定；
2. 齿轮和轴位姿仍依赖仿真真值；
3. 接触力没有对应真实传感器方案；
4. 没有真实控制延迟、通信抖动和急停链路；
5. 成功判定依赖插入深度真值；
6. 没有验证齿轮抓持稳定性；
7. 没有完成真实机械臂工作空间和速度安全评估。

## 7. Clip 00 交付物映射

- `configs/task-specification.yaml`：任务规格和观测来源；
- `configs/acceptance-criteria.yaml`：指标测量方法、样本数、种子和扰动范围；
- `configs/failure-codes.yaml`：失败分类、严重程度、可重试性和默认动作；
- `capstone_clip00/models.py`：强类型合同与校验；
- `scripts/validate_configs.py`：进入 Clip 01 前的配置门禁；
- `scripts/summarize_episodes.py`：后续环境生成日志后的统一离线评测入口。
